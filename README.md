# TJK CHAT — Мессенҷер

[![E2E](https://github.com/userm098765432q-code/tjk-chat/actions/workflows/e2e.yml/badge.svg)](https://github.com/userm098765432q-code/tjk-chat/actions/workflows/e2e.yml)

Мессенҷери веб бо интерфейси тоҷикӣ ва тарҳи **сиёҳу тиллоӣ** (HTML/CSS/JS дар як файл).

## Имконият
- Пардаи даромадан: **ном, насаб, рақами телефон (+992), email** бо тасдиқи маълумот
- Маълумоти корбар дар `localStorage` нигоҳ дошта мешавад (даромадани худкор)
- Тугмаи баромадан (⎋) дар сорбар
- Гуфтугӯҳои намунавӣ, ҷавоби корбари симулятсияшуда, ҷустуҷӯ
- Ҷавоб бо иқтибос, нест кардани паём, фиристодани сурат, панели эмодзи
- Тикҳои ҳолат: ✓ (фиристода) → ✓✓ кабуд (хондашуда)
- Паёми овозӣ: 🎙 сабт тавассути MediaRecorder (то 2 дақиқа), пахшкунак бо мавҷҳо
- Чатҳо дар `localStorage` нигоҳ дошта мешаванд — паёмҳо баъди навсозӣ боқӣ мемонанд
- Мутобиқ ба мобил

## Истифода
`index.html`-ро дар браузер кушоед.

## Тестҳои E2E (Cypress)
Лозим: Node.js 18+ (`nodejs.org`).

```bash
npm install          # як бор
npm run e2e          # сарпарастӣ дар терминал (headless)
npm run e2e:open     # интерфейси Cypress
```

`npm run e2e` худ сервери локалиро оғоз мекунад ва 8 сенарияи даромаданро месанҷад.

## Чеклисти санҷиш

### Даромадан
- [ ] Форма бо майдонҳои холӣ: 4 паёми хато нишон дода мешавад
- [ ] Ном/насаб бо 1 ҳарф радд мешавад
- [ ] Телефон: `+992 92 123 4567` ва `+992921234567` қабул; `+992 92-123-4567` радд
- [ ] Email-и бе `@` ё бе домен радд мешавад
- [ ] Баъди даромадан: ном дар поёни сорбар, аватар аз ҳарфҳои аввал
- [ ] Баъди навсозии саҳифа: даромадан нигоҳ дошта мешавад (автологин)

### Муқовимат бо маълумоти вайрон (localStorage)
- [ ] `localStorage.tjkchat_user = '{broken'` → пардаи даромадан, бе crash
- [ ] `localStorage.tjkchat_user = '12345'` → пардаи даромадан, бе crash
- [ ] Объекти бе `firstName` → пардаи даромадан, бе crash

### Гуфтугӯ
- [ ] Паём фиристода мешавад; input тоза; тугма ғайрифаъол; тик ✓
- [ ] Паём: тик ✓ → баъди ~0.6s ✓✓ → баъди ~1.2s ✓✓ кабуд + тайпинг → ҷавоб
- [ ] Ҷустуҷӯ: натиҷаи холӣ 0 контакт; тозакунӣ ҳамаро бармегардонад
- [ ] Бэҷи unread ҳангоми кушодани чат нобуд мешавад; ҳангоми гузариш афзоиш мекунад

### Паёми овозӣ
- [ ] 🎙 клик → панели сабт бо таймер нишон дода мешавад
- [ ] ➤ дар панел → паёми овозӣ бо мавҷҳо ва давомнокӣ фиристода мешавад
- [ ] ▶ пахш → овоз менавозад, мавҷҳо ҳаракат мекунанд; дубора → таваққуф
- [ ] 🗑 дар панел → сабт бекор мешавад, паём фиристода намешавад
- [ ] Сабти камтар аз 1 сония радд мешавад
- [ ] Сабти худкор баъди 2 дақиқа фиристода мешавад
- [ ] Ҷавоб ба овоз «🎙 Овоз» менависад; паём баъди навсозӣ боқӣ мемонад

### Нигоҳдории чатҳо
- [ ] Паём фиристода мешавад → `tjkchat_chats` дар localStorage пайдо мешавад
- [ ] Навсозии саҳифа (F5) → паёмҳо, тикҳо, иқтибосҳо ва паёмҳои нестшуда боқӣ мемонанд
- [ ] `localStorage.tjkchat_chats = '{broken'` ё `'42'` → демо-чатҳо бе crash бар мегарданд
- [ ] Паёмҳои вайрон дар массив фильтр мешаванд; массиви холӣ → демо-чатҳо

### Танзимот ва қулфи PIN

- [ ] Ранги асосӣ (5 ранг) --gold-ро иваз мекунад; баъди reload боқӣ мемонад
- [ ] Ҳарфи паём (3 дараҷа) ва заминаи чат (4 вариант) боқӣ мемонанд
- [ ] Ҷавоби корбари дуюм хомӯш карда мешавад — паёми нав намеояд
- [ ] Садои паём хомӯш карда мешавад; ҳолат дар localStorage
- [ ] PIN (4 рақам): гузоштан, такрор, радди нодуруст, хомӯш кардан
- [ ] 🔒 қулф: клавиатураи рақамӣ, 4 нуқта, PIN-и нодуруст ларзиш медиҳад; баъди reload боз мепурсад
