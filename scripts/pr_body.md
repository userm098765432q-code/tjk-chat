## Тавсифи тағйирот

Мессенҷери веби пурраи TJK CHAT бо интерфейси тоҷикӣ ва тарҳи сиёҳу тиллоӣ.

### Асосӣ
- **Пардаи даромадан:** ном, насаб, телефон (+992 XX XXX XXXX), email — бо тасдиқи пурраи маълумот
- **Профил дар localStorage:** автологин баъди навсозӣ; ҳимоя аз JSON-и вайрон (бе crash)
- **Тугмаи баромадан (⎋)** — тозакунии пурраи ҳолат

### Чат
- Ҷавоб бо иқтибос (replyTo), нест кардани паём (ҷойгирдор), фиристодани сурат (FileReader)
- Паёми овозӣ тавассути MediaRecorder (то 2 дақиқа, худкор-фиристодан, сабти <1с радд мешавад) бо пахшкунаки мавҷдор
- Панели 22 эмодзи
- Тикҳои ҳолат: ✓ → ✓✓ кабуд (хондашуда)
- Ҷустуҷӯи контактҳо, бэҷи unread, ҷавоби худкор бо индикатори typing
- **Нигоҳдории чатҳо дар localStorage** — паёмҳо баъди F5 боқӣ мемонанд (бо ҳимоя аз маълумоти вайрон ва quota)

### Тестҳо
- **Cypress E2E: 8/8 мегузаранд** — ҷараёни пурраи даромадан, validation, маълумоти вайрон, logout
- Server-и статикӣ бе dependencies (`scripts/serve.cjs`)
- Иҷро: `npm install && npm run e2e`

### Тарҳ
- Сиёҳу тиллоӣ (`#0a0a0a` + `#d4af37`), CSS-тагирёфтаҳо, мутобиқ ба мобил (<=720px)
